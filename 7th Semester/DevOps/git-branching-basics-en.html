Cheat sheet

The three ideas

TermWhat it is
CommitA snapshot of your project, linked to its parent commit.
BranchA movable label pointing at one commit. Creating one is instant because no files are copied.
HEADWhere you are now. New commits go onto the branch HEAD points at.

Create and switch

git branch feature          # create the label (you stay where you are)
git switch feature          # move HEAD to it
git switch -c feature       # create and switch in one go
git checkout -b feature     # the older way to do the same
git switch -                # jump back to the previous branch

List, rename, delete

git branch                  # list local branches (* = current)
git branch -v               # also show each branch's last commit
git branch -a               # include remote branches
git branch -m old new       # rename
git branch -d feature       # safe delete (only if merged)
git branch -D feature       # force delete (may lose work)

Remotes

git clone <url>                 # copy a repo from the server
git push -u origin feature      # publish a branch and link it (once)
git fetch origin                # download news, change nothing of yours
git pull                        # fetch + merge
git pull --rebase               # fetch + rebase (straighter history)

Stash and detached HEAD

git stash                   # shelve uncommitted work
git stash pop               # bring it back
git stash list              # see all stashes
git switch --detach c2      # look at an old commit (detached HEAD)
git switch -c experiment    # save work made while detached
Common mistakes: forgetting that git branch name does not switch to it, deleting an unmerged branch with -D, and committing in detached HEAD without creating a branch first.
